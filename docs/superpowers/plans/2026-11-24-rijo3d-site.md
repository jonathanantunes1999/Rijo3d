# Site Rijo3d Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Site institucional de uma página para a Rijo3d (impressão 3D): galeria, história, contactos e pedido de encomenda por formulário e WhatsApp.

**Architecture:** HTML, CSS e JavaScript simples, sem framework nem passo de build, para qualquer pessoa ou o Claude editarem com facilidade. A galeria é desenhada a partir de um único ficheiro de dados (`data/galeria.js`), para que um painel (Sanity) possa substituí-lo mais tarde sem refazer a página. O formulário envia por Web3Forms; o WhatsApp é um link `wa.me`.

**Tech Stack:** HTML5, CSS3, JS (ES modules), Playwright (já instalado no ambiente) para os testes. Hospedagem estática (Cloudflare Pages ou Netlify).

**Spec:** `docs/superpowers/specs/2026-11-24-rijo3d-site-design.md`

## Global Constraints

- Língua do site: português de Portugal (`<html lang="pt-PT">`), sem "tu/você" brasileiro.
- Sem frameworks, sem passo de build, sem dependências em runtime (fontes via Google Fonts são a única exceção externa permitida, com `font-display: swap`).
- Sem loja online: sem carrinho, pagamentos ou stock.
- Sem custos recorrentes obrigatórios: tudo tem de correr em hospedagem estática grátis.
- Conteúdo real do cliente (fotos, texto da história, logótipo, cores, contactos, número de WhatsApp, chave Web3Forms) ainda não existe. Usar marcadores explícitos `TODO-CLIENTE:` e nunca inventar factos sobre a empresa.
- Nunca copiar textos, imagens ou marca do site de referência (vbfigures.com).
- Design: usar as skills `anthropic-skills:ui-ux-pro-max` e `anthropic-skills:frontend-ui-engineering` nas tarefas 2 a 4 e 6.
- Mobile first, sem scroll horizontal a 320px, 375px, 768px e 1280px de largura.

## Review Focus

1. Galeria com zero itens: mostra uma mensagem em vez de uma secção vazia e sem erro na consola.
2. Nomes de ficheiro de imagem com espaços ou acentos e legendas muito longas: não partem o layout nem os caminhos.
3. Formulário enviado só com espaços nos campos obrigatórios: é rejeitado antes de enviar.
4. JavaScript desativado: o formulário e o link de WhatsApp continuam a funcionar e a galeria mostra as imagens (via `<noscript>`).
5. Ecrã de 320px com textos longos e o lightbox aberto: sem corte nem scroll horizontal, e fecha com Esc e com toque fora.
